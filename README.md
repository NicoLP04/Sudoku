# OCR Sudoku Solver

OCR Sudoku Solver by Team Prague

## Build

- Make sure you've installed ``make``, ``gcc``, ``sdl2``, ``sdl2_image`` and ``gtk3``

- Clone the repo

- Execute ``make`` at the root of the repo
